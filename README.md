A Sunday wire tape for 22 November 2026: one live market lead, three flash dispatches, 34 distinct threads on a dated timeline, and a plotted world map. Earlier event dates stay attached to their stories.

The image is `entry.png`. The competition runner uses `main.py`, which copies that image to `/output/entry.png` with Python's standard library. `render.py` uses Pillow to draw the image; it does not run in the competition sandbox.

## Run

```sh
python3 -P -s main.py
```

The default output directory is `/output`; set `MAKEFUN_OUTPUT_DIR` to preview it locally.
